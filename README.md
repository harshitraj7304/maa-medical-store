# 🏥 MA Medical Store

A modern medical ecommerce web application built using **React JS** and **Tailwind CSS**.  
This project allows users to browse medicines, add products to cart, book lab tests, and track their medical orders through a clean and responsive interface.

---

# 🚀 Features

- 💊 Browse medicines with pricing
- 🛒 Add to cart functionality
- ➕ Increase & decrease product quantity
- 🧪 Lab test booking system
- 📦 Order tracking page
- 📱 Fully responsive UI
- ⚡ Fast React-based frontend
- 🎨 Modern Tailwind CSS design
- 🔄 Multi-page navigation using React Router

---

# 🛠 Tech Stack

- React JS
- Tailwind CSS
- JavaScript
- React Router DOM
- Vite

# ⚙️ Installation & Setup

Clone the repository

```bash
git clone https://github.com/harshitraj7304/maa-medical-store.git
```

Go to project folder

```bash
cd maa-medical-store
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```
